| `synthetic/` | Small, generated datasets used by the curriculum | Yes |

## Labelling rule

Any file this project generates is **synthetic** and must say so in three
places: the filename (`*_synthetic.csv`), a header comment or column note inside
the file, and the folder's manifest below.

Synthetic data exists so the course is reproducible without licence-restricted
downloads. It carries no biological meaning.
