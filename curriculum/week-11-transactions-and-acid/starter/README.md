# starter/

Skeleton files for this week, containing `TODO:` markers where your work goes.

Rules:

- Never a finished solution. Instructor guidance lives in
  `instructor/solution-notes/`.
- Copy a starter file to its destination in `project/` (or edit in place where
  the week says so) and replace every `TODO:`.
- If a starter file references a table or module that does not exist yet, that is
  a sign you skipped a prerequisite week.
