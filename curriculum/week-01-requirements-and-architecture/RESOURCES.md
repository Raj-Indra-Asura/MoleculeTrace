# Week 01 — Resources

Official documentation first. Add a link only after you have used it.

## Required reading

- PostgreSQL 16 — architectural fundamentals (processes, client/server model):
  https://www.postgresql.org/docs/16/tutorial-arch.html
- PostgreSQL 16 — concepts: databases, schemas and the search path:
  https://www.postgresql.org/docs/16/ddl-schemas.html
- PostgreSQL 16 — database roles and privileges, i.e. who may do what:
  https://www.postgresql.org/docs/16/user-manag.html and
  https://www.postgresql.org/docs/16/ddl-priv.html
- PostgreSQL 16 — data integrity: constraints:
  https://www.postgresql.org/docs/16/ddl-constraints.html
- Mermaid — flowchart syntax, used for the three-tier diagram:
  https://mermaid.js.org/syntax/flowchart.html
- ISO/IEC/IEEE 29148 overview of requirement characteristics (necessary,
  unambiguous, verifiable, singular, feasible, traceable):
  https://www.iso.org/standard/72089.html

## Reference

- PostgreSQL 16 documentation: https://www.postgresql.org/docs/16/
- PostgreSQL 16 — transactions, for the atomicity argument:
  https://www.postgresql.org/docs/16/tutorial-transactions.html
- PostgreSQL 16 — backup and restore, for the recoverability requirement:
  https://www.postgresql.org/docs/16/backup.html
- FastAPI — first steps (the application tier):
  https://fastapi.tiangolo.com/tutorial/first-steps/
- Streamlit — main concepts (the presentation tier):
  https://docs.streamlit.io/get-started/fundamentals/main-concepts
- Mermaid live editor, for checking a diagram renders:
  https://mermaid.live/
- Architecture decision records, the original format:
  https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions
