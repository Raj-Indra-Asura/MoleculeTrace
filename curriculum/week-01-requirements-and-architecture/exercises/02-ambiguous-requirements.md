at least one test of the **requirement-quality checklist**:

| # | Test | Question it answers |
|---|------|---------------------|
| Q1 | Atomic | Does it state exactly one obligation? |

| Q3 | Unambiguous | Can it be read only one way? |
| Q4 | Necessary | Does it trace to an actor or objective? |
| Q5 | Implementation-free | Does it state the need rather than the design? |
| Q6 | Traceable | Does it have a stable ID other documents can cite? |
