# Relational Algebra — reference pointer

Relational algebra is the formal query language underneath SQL: selection, projection, Cartesian product, join, union, difference, rename and division. In MoleculeTrace it is the vocabulary used to reason about how activity observations are filtered and combined with molecules, targets and assays before any SQL is written.

The topic is taught and exercised in week 06, where each algebra expression is paired with an equivalent SQL statement over the MoleculeTrace schema, and equivalent rewritings are compared. Query rewriting reappears in week 22 when the planner's choices are examined.
