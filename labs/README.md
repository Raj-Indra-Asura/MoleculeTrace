# labs/ — topic index

`labs/` is a **reference index only**. Each file is a short pointer: a summary of
a cross-cutting topic and a link to the curriculum week (or weeks) where the
topic is actually taught and exercised.

Nothing executable lives here. No starter code, no exercises, no tests, no
expected outputs. If content ever exists in both places,
`curriculum/week-XX/` is authoritative and the `labs/` file must be corrected to
point there. This rule exists to prevent duplicate or conflicting versions of the
same exercise.
