# instructor/

Guidance for whoever grades or mentors this course — including the student, but
only *after* attempting the work.

| Folder | Contents |
|--------|----------|
| `rubrics/` | The shared 10-point rubric and any week-specific criteria |
| `validation/` | How each week's checkpoint is verified, and what to do when it fails |
| `solution-notes/` | Reference solutions, expected pitfalls and grading notes |

**Rule:** finished solutions live here and nowhere else. Student-facing folders
(`curriculum/*/starter/`, `curriculum/*/exercises/`, `project/`) contain `TODO:`
markers only.
