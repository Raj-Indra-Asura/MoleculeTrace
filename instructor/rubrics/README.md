# Rubrics

Every week is scored out of 10 with the same five criteria. Week-specific notes
may sharpen what "fully correct" means, but never change the weights.

| Criterion | Weight | 0 | 1 | 2 |
|-----------|--------|---|---|---|
| Correctness of required exercises | 3 | Not attempted or mostly wrong | Partly correct; validation fails | Fully correct; validation passes |
| Depth of conceptual understanding | 2 | Notes/reflection absent | Restates the material | Explains in own words with a MoleculeTrace example |
| Quality of the project improvement | 2 | No visible improvement | Works but undocumented or untidy | Clean, documented, tested improvement |
| Validation and evidence | 2 | Nothing run | Some checks pass; evidence partial | All checks pass; portfolio evidence saved |
| Git hygiene and documentation | 1 | No meaningful commits | Inconsistent messages or stale docs | Conventional commits; progress table updated |

Score = Σ(criterion score × weight) ÷ 2, rounded to the nearest whole number.
Maximum 10. **Pass mark: 7.**

Add `week-XX.md` here only when a week needs extra criteria detail.
