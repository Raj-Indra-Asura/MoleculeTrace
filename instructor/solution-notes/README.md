# Solution notes

Reference solutions and grading guidance, one file per week (`week-XX.md`).

**Students: read these only after submitting your own attempt.**

Each file should contain:

- a reference solution for every required exercise;
- the two or three mistakes most students make, and the symptom of each;
- acceptable alternative answers (especially for design and SQL exercises, where
  several correct schemas or queries exist);
- guidance on where to award partial credit;
- an estimate of how long each block actually takes, so the five-hour budget can
  be corrected if it drifts.

Nothing from this folder may be copied into student-facing folders.
